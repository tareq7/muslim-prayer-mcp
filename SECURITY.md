# Security Policy

## Reporting a Vulnerability

If you discover a security issue or vulnerability in this repository, please report it responsibly by opening a Private Vulnerability Report on GitHub or emailing the maintainer.

Please include:
* Description of the vulnerability
* Steps or code to reproduce the issue
* Potential impact

We take location data privacy and security seriously. All coordinates are truncated to 2 decimal places (`~1.1km`), and raw location metadata is never surfaced in tool responses to LLM contexts.
